소스라이브 알림 기능 가이드

파트너 계정 내 알림 채널 설정 기준과 브릿지알림 / 카카오알림톡의 운영 구조를 내부에서 동일하게 이해하기 위한 문서입니다.

1

알림 채널 구조

소스라이브에서 설정 가능한 알림 채널은 브릿지알림과 카카오알림톡 2가지입니다. 두 채널은 모비더가 파트너 계정 메뉴에서 선택할 수 있습니다.

브릿지알림

고객사 알림 시스템과 연동하는 방식입니다. 알림 버튼 클릭 값을 고객사에 전달하고, 고객사 콜백을 받아 UI 상태를 변경합니다.

고객사 발송 시스템 연동 앱푸시 가능
카카오알림톡

모비두가 비회원 대상 알림 발송을 대행하는 방식입니다. 카카오 채널 정보를 받아 인포빕 연동 후 발송합니다.

모비두 대행 비회원 방식 정보성 메시지
알림 채널 설정 위치 주요 목적 발송 주체
브릿지알림 파트너 계정 메뉴 고객사 알림 시스템과 연동 고객사
카카오알림톡 파트너 계정 메뉴 모비두가 비회원 알림 발송 대행 모비두
중요 기준
고객사가 직접 브릿지 방식으로 카카오알림톡, SMS, LMS, MMS 등을 발송하는 경우에는 파트너 계정에서 카카오알림톡이 아니라 브릿지알림을 선택해야 합니다. 파트너 계정에서 카카오알림톡을 선택하는 경우는 모비두가 대행 발송하는 경우에 한정됩니다.
2

브릿지알림

2-1. 개념

브릿지알림은 소스라이브가 직접 알림을 발송하는 방식이 아니라, 고객사의 알림 시스템과 연결하는 방식입니다. 고객이 알림 버튼을 클릭하면 소스라이브는 “알림 버튼이 클릭되었다”는 값을 고객사 시스템으로 전달합니다.

이후 고객사는 로그인 여부, 회원 여부, 수신 동의 여부 등을 확인한 뒤 소스라이브로 콜백을 전달하고, 소스라이브는 콜백 값 또는 토큰 정보를 기준으로 알림 신청 UI를 변경합니다.

2-3. 노출 가능 위치

구분 사용 가능 여부 설정 / 작업 기준
쇼룸 가능 고객사가 쇼룸 > 테마설정에서 버튼 노출 가능
개별 예고 편성표 / 사전 페이지 가능 모비더 설정 및 별도 브릿지 연동 작업 필요
쇼룸 + 사전 페이지 모두 사용 가능 각각 별도 작업 필요
주의사항
쇼룸 브릿지 알림과 사전 페이지 브릿지 알림은 각각 별도 작업이 필요합니다. 둘 다 사용하려면 총 2번의 작업이 필요합니다.

2-4. 사전 페이지 브릿지 알림 주의사항

사전 페이지 브릿지 알림은 고객사 알림 시스템에 연결해야 하는 구조입니다. 사전 페이지는 방송 시작 후 플레이어 페이지로 전환되기 때문에, 플레이어가 고객사 서비스 내에서 iframe 방식으로 적용되어 있어야 합니다.

항목 기준
쇼룸 브릿지 알림 일반 방식 가능
사전 페이지 브릿지 알림 iframe 방식 필요
플레이어에서 소스라이브 링크 사용 브릿지 알림 적용을 위해 iframe 형태 필요
이유 사전 페이지는 방송 시작 후 플레이어 페이지로 전환되며 고객사 알림 시스템과 연결되어야 하기 때문

2-5. 비회원 직접 발송 예외 케이스

고객사가 브릿지알림을 사용하면서 비회원 대상으로 직접 알림을 발송하고 싶어할 수 있습니다. 이 경우 고객사가 브릿지 값을 받은 뒤, 이름 / 연락처 등을 입력받는 팝업 또는 템플릿을 직접 노출해야 합니다.

고객사 개발 필요 항목
  • 이름 / 연락처 입력 팝업 또는 화면
  • 개인정보 수집 및 동의 처리
  • 알림 신청 정보 저장
  • 발송 템플릿 개발
  • SMS / LMS / MMS / 카카오알림톡 발송 시스템
  • 발송 결과 관리
운영 주의사항

비회원 기반으로 처리할 경우 쿠키가 삭제되면 알림 신청 상태 정보가 사라질 수 있습니다. 내부 안내 시 가능하면 회원 기반 알림 신청으로 유도하는 것이 좋습니다.

3

카카오알림톡

3-1. 개념

카카오알림톡은 모비두가 고객사의 비회원 알림 발송을 대행하는 방식입니다. 내부에서는 보통 “힘펠 방식”이라고 표현하는 케이스입니다.

카카오알림톡 사용 시 고객사의 카카오 채널 정보를 받아 인포빕에 연결한 뒤, 모비두가 알림 발송을 대행합니다.

3-2. 노출 가능 위치

구분 카카오알림톡 대행 사용 가능 여부
개별 예고 편성표 / 사전 페이지 가능
쇼룸 불가
쇼룸 브릿지 알림 별도 동작

3-3. 설정 기준

카카오알림톡은 모비두가 대행하는 방식일 때만 파트너 계정에서 카카오알림톡으로 선택해야 합니다. 고객사가 직접 예고 편성표에 브릿지를 연결해서 카카오알림톡을 사용하는 경우에는 브릿지알림을 선택해야 합니다.

상황 파트너 계정 선택값
모비두가 카카오알림톡 발송 대행 카카오알림톡
고객사가 직접 브릿지로 카카오알림톡 발송 브릿지알림
고객사가 직접 SMS / LMS / MMS 발송 브릿지알림
고객사가 앱푸시 발송 브릿지알림

주의사항
카카오알림톡은 단순 알림톡, 즉 정보성 메시지만 대행 가능합니다. 광고성 내용이 포함된 메시지는 모비두 대행 방식으로 발송할 수 없습니다. 고객사가 광고성 메시지를 희망하는 경우, 브릿지알림을 통해 직접 발송해야 합니다.

내부 요약

소스라이브 알림 채널은 브릿지알림과 카카오알림톡 2가지입니다.

브릿지알림은 고객사 알림 시스템과 연동하는 방식이며, 실제 발송은 고객사가 처리합니다. 쇼룸과 사전 페이지 모두 사용할 수 있지만 각각 별도 작업이 필요합니다. 사전 페이지 브릿지 알림은 플레이어 구조상 iframe 방식 적용이 필요합니다.

카카오알림톡은 모비두가 비회원 알림을 대행하는 방식이며, 개별 예고 편성표에만 노출 가능합니다. 카카오 채널 정보와 인포빕 연동이 필요하고, 모비두 템플릿을 사용합니다. 단, 정보성 메시지만 대행 가능하며 광고성 메시지는 고객사가 브릿지알림을 통해 직접 발송해야 합니다.

앱푸시는 별도 대행 채널이 아니며, 고객사 앱푸시 시스템과 브릿지 방식으로 연동해야 합니다.
