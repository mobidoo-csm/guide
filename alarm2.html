소스라이브 알림 기능 안내

소스라이브에서는 라이브 방송 전 고객이 알림을 신청할 수 있도록 알림 기능을 제공합니다. 고객사의 운영 방식에 따라 브릿지알림 또는 카카오알림톡 방식을 선택할 수 있습니다.

1

알림 방식 요약

알림 기능은 고객사의 회원 시스템 연동 여부와 발송 방식에 따라 아래 2가지 방식 중 선택하여 사용할 수 있습니다.

🔗브릿지알림

고객사 알림 시스템과 연동하는 방식입니다. 고객이 알림 버튼을 클릭하면 해당 정보를 고객사 시스템으로 전달하고, 실제 알림 발송은 고객사 시스템에서 처리합니다.

회원 시스템 연동 앱푸시 가능 고객사 직접 발송
💬카카오알림톡

소스라이브에서 비회원 대상 알림 발송을 대행하는 방식입니다. 고객사의 카카오 채널 정보를 받아 발송 연동 후 알림톡을 발송합니다.

2

브릿지알림

2-1. 브릿지알림이란?

브릿지알림은 소스라이브 알림 버튼을 고객사의 알림 시스템과 연결하는 방식입니다. 고객이 소스라이브 화면에서 알림 버튼을 클릭하면, 소스라이브는 해당 클릭 정보를 고객사 시스템으로 전달합니다.

이후 고객사 시스템에서 로그인 여부, 회원 여부, 알림 수신 가능 여부 등을 확인한 뒤 소스라이브로 결과를 전달합니다. 소스라이브는 전달받은 결과를 기준으로 알림 신청 UI를 변경합니다.

확인 필요
쇼룸과 개별 예고 편성표는 각각 별도 연동 작업이 필요합니다. 두 위치 모두 알림 기능을 사용하려는 경우, 각 영역별 연동 범위를 사전에 확인해야 합니다.

2-4. 개별 예고 편성표 브릿지알림 주의사항

개별 예고 편성표에서 브릿지알림을 사용하는 경우, 고객사 알림 시스템과의 연결이 필요합니다. 또한 개별 예고 편성표는 방송 시작 후 플레이어 페이지로 전환되는 구조이므로, 플레이어 적용 방식에 대한 확인이 필요합니다.

고객사 서비스 내에서 플레이어를 사용하는 경우 iframe 방식 적용이 필요할 수 있습니다.

2-5. 비회원 대상 직접 발송을 원하는 경우

브릿지알림을 사용하면서 비회원 대상으로 고객사가 직접 알림을 발송하려면, 고객사 측에서 이름, 연락처 등을 입력받는 화면을 직접 구성해야 합니다.

이 경우 고객사에서 알림 신청 정보를 저장하고, 자체 발송 시스템을 통해 메시지를 발송하게 됩니다.

📝고객사 준비 필요 항목
  • 이름 / 연락처 입력 화면
  • 개인정보 수집 및 동의 처리
  • 알림 신청 정보 저장
  • 발송 메시지 템플릿
  • SMS / LMS / MMS / 카카오알림톡 등 발송 시스템
⚠️운영 주의사항

비회원 방식은 쿠키 삭제 시 알림 신청 상태 정보가 유지되지 않을 수 있습니다. 안정적인 운영을 위해서는 회원 기반 알림 신청 방식을 권장합니다.

3

카카오알림톡

3-1. 카카오알림톡이란?

카카오알림톡은 소스라이브에서 비회원 대상 알림 발송을 대행하는 방식입니다. 고객사가 카카오 채널 정보를 제공하면, 소스라이브에서 발송 연동을 진행하고 알림톡을 발송합니다.

3-2. 사용 가능 위치

카카오알림톡 방식은 개별 예고 편성표에서 사용할 수 있습니다. 쇼룸에서는 카카오알림톡 대행 방식이 직접 적용되지 않으며, 쇼룸 알림이 필요한 경우 브릿지알림 방식으로 별도 연동이 필요합니다.

3-3. 주요 특징

✓
개별 예고 편성표에 노출 가능
✓
비회원 대상 알림 신청 가능
✓
소스라이브에서 발송 대행
✓
고객사 카카오 채널 정보 필요
✓
소스라이브 템플릿 기준으로 발송
✓
카카오알림톡 외 MMS / LMS / SMS 발송 가능

3-4. 주의사항

정보성 메시지만 발송 가능
소스라이브에서 대행하는 카카오알림톡은 정보성 메시지만 발송 가능합니다. 할인, 구매 유도, 이벤트 참여 독려 등 광고성 내용이 포함된 메시지는 대행 발송이 어렵습니다.

광고성 메시지를 발송하고자 하는 경우에는 고객사에서 직접 발송 시스템을 운영해야 합니다. 이 경우 브릿지알림 방식으로 고객사 시스템과 연동하여 발송하는 형태로 진행할 수 있습니다.

4

앱푸시 사용을 원하는 경우

고객사 앱푸시를 사용하려는 경우에는 브릿지알림 방식으로 연동해야 합니다. 소스라이브에서 앱푸시 발송을 대행하지는 않습니다.

고객이 소스라이브 화면에서 알림 버튼을 클릭하면 해당 정보를 고객사 시스템으로 전달하고, 고객사 앱푸시 시스템에서 실제 푸시 발송을 처리하는 구조입니다.
5

어떤 방식을 선택하면 좋을까요?

고객사 니즈 권장 방식
비회원에게 간단한 방송 알림을 보내고 싶어요 카카오알림톡
소스라이브에서 알림 발송까지 대행해주면 좋겠어요 카카오알림톡
고객사 회원 시스템과 연결하고 싶어요 브릿지알림
고객사 앱푸시로 알림을 보내고 싶어요 브릿지알림
광고성 메시지도 발송하고 싶어요 브릿지알림
쇼룸에서도 알림 버튼을 사용하고 싶어요 브릿지알림
개별 예고 편성표에서 알림 버튼을 사용하고 싶어요 브릿지알림 또는 카카오알림톡

준비 필요 사항

🔗브릿지알림 사용 시
  • 고객사 로그인 / 회원 시스템 연동 가능 여부
  • 알림 버튼 클릭 값 수신 가능 여부
  • 소스라이브로 콜백 전달 가능 여부
  • 실제 알림 발송 시스템 보유 여부
  • 앱푸시, SMS, LMS, MMS, 카카오알림톡 등 발송 방식
  • 개별 예고 편성표 사용 시 iframe 적용 가능 여부
💬카카오알림톡 사용 시
  • 고객사 카카오 채널 정보
  • 알림톡 발송에 필요한 기본 정보
  • 알림 신청 시 노출될 이용약관 URL
  • 발송 문구 검토
카카오알림톡은 정보성 메시지만 발송 가능하므로, 문구 내 광고성 표현이 포함되지 않도록 사전 확인이 필요합니다.

최종 정리

소스라이브 알림 기능은 고객사의 운영 방식에 따라 브릿지알림 또는 카카오알림톡 방식으로 제공됩니다.

브릿지알림은 고객사 알림 시스템과 연동하는 방식으로, 회원 기반 알림, 앱푸시, 광고성 메시지 발송 등 고객사 자체 운영이 필요한 경우에 적합합니다.

카카오알림톡은 소스라이브에서 비회원 대상 알림 발송을 대행하는 방식으로, 개별 예고 편성표에서 간단한 정보성 알림을 발송하고자 할 때 적합합니다.

쇼룸과 개별 예고 편성표는 각각 별도 연동이 필요할 수 있으므로, 사용하고자 하는 위치와 발송 방식을 사전에 확인한 뒤 진행해야 합니다.
